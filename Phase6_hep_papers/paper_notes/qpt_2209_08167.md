## Core Idea

Proposes a **Quantum Transformer (QT)** that applies quantum circuits
at multiple points in the standard Transformer pipeline.

Unlike arXiv:2110.06510 (which only quantises W_Q/K/V projections),
this paper proposes quantising the **feedforward sublayer** as well.

## Architecture

```
Input patches
    ↓
Classical patch embedding
    ↓
Classical positional encoding
    ↓
┌─────────────────────────────────┐
│ Quantum Transformer Block       │  × N layers
│   ├── Classical LayerNorm       │
│   ├── Quantum Multi-Head Attn   │  ← VQC replaces W_Q/K/V
│   ├── Classical residual        │
│   ├── Classical LayerNorm       │
│   └── Quantum FFN               │  ← VQC replaces Linear layers
└─────────────────────────────────┘
    ↓
Classical classifier head
```

---

## Quantum Multi-Head Attention

Each head uses a **data re-uploading circuit**:
```
Repeat L times:
    AngleEmbedding(x)        ← re-upload input at each layer
    Variational layer (Ry rotations + CNOT)
```

Data re-uploading (Perez-Salinas et al.) is key:
- Classical neural nets stack linear transforms; quantum circuits
  can only apply a unitary once per "layer"
- Re-uploading the input at each layer approximates the expressive
  power of deep classical networks with fewer qubits

## HEP Application (Most Relevant to QMLHEP5)

Section 5 applies the Quantum Transformer to **jet tagging** in HEP:

### Task
Classify jets as top quarks (signal) vs QCD background (noise).
Same task as QMLHEP Task II.

### Data
- Top quark tagging benchmark dataset (Kasieczka et al.)
- 14 particle-level features per jet constituent
- ~1.2M training jets, 400K test jets
- Binary classification: top = 1, QCD = 0

### Features Used (14 per constituent)
```
E, px, py, pz          — 4-momentum
η, φ                   — rapidity, azimuthal angle
pT                     — transverse momentum
charge                 — particle charge
is_electron, is_muon   — lepton flags
is_photon              — photon flag
is_charged_hadron      — charged hadron flag
is_neutral_hadron      — neutral hadron flag
is_EFlow_photon        — EM flow photon flag
```

### Results
| Model | AUC | Accuracy |

| Quantum Transformer | 0.981 | 93.8% |
| ParticleNet (baseline) | 0.986 | 94.2% |

Quantum Transformer matches classical within ~0.3% on this benchmark.

## Data Re-uploading (Key Technique)

Standard quantum circuit (one embedding):
```
AngleEmbedding(x) → U1(θ1) → measure    ← only one "layer" of data
```

Data re-uploading (L repetitions):
```
AngleEmbedding(x) → U1(θ1) → AngleEmbedding(x) → U2(θ2) → ... → measure
```

Why it works:
- Each re-upload creates a new Fourier component in the function space
- L repetitions ≈ L-layer classical network in expressibility
- Proved universal approximation for L → ∞ (Perez-Salinas et al. 2020)

## For Your QVIT Prototype (Phase 7)

Use **angle encoding + data re-uploading** (this paper's approach)
rather than amplitude encoding (2110.06510).

Reasons:
1. Angle encoding scales as O(n) gates — practical for NISQ
2. Amplitude encoding scales as O(2^n) — intractable for n > 10
3. Re-uploading compensates for lower expressibility of angle encoding
4. PennyLane's `AngleEmbedding` implements this directly

```python
# Recommended for Phase 7 QVIT
@qml.qnode(dev, interface="torch")
def quantum_attention_head(inputs, weights):
    for l in range(n_layers):
        qml.AngleEmbedding(inputs, wires=range(n_qubits))  # re-upload each layer
        for i in range(n_qubits):
            qml.RY(weights[l, i], wires=i)
        for i in range(n_qubits - 1):
            qml.CNOT(wires=[i, i+1])
    return [qml.expval(qml.PauliZ(w)) for w in range(n_qubits)]
```
