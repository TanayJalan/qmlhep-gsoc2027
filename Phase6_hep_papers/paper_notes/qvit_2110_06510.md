> **Year:** 2022

## Core Idea

Replace the linear projections W_Q, W_K, W_V in multi-head attention
with **orthogonal quantum layers** implemented as unitary quantum circuits.

Classical attention:
```
Q = X @ W_Q     W_Q ∈ R^(d×d)
K = X @ W_K
V = X @ W_V
scores = softmax(Q @ K.T / sqrt(d)) @ V
```

QVIT attention:
```
Q = U_Q(θ) |x⟩     U_Q = parameterised unitary circuit
K = U_K(θ) |x⟩
V = U_V(θ) |x⟩
scores = softmax(Q @ K.T / sqrt(d)) @ V
```

The key claim: unitary matrices are more expressive per parameter than
arbitrary linear matrices because they preserve inner products (isometric).

---

## Architecture Details

### Quantum Orthogonal Layer (QOL)
- Encodes input vector as a quantum state via amplitude encoding
- Applies parameterised unitary U(θ) = product of Givens rotations
- Measures expectation values → output vector
- Equivalent to multiplying by an **orthogonal matrix** (subset of unitary)

### Why Orthogonal / Unitary?
- Orthogonal matrices are distance-preserving
- Gradient flow is stable (no vanishing/exploding) — eigenvalues on unit circle
- Natural for quantum hardware — all gates are unitary
- Connects to orthogonal neural networks (Cayley parameterisation)

### Patch Embedding
- Same as classical ViT: split image into patches, linear project
- **Kept classical** in the paper — quantum advantage is in attention

### Position Encoding
- Same as classical ViT: learned absolute PE
- **Kept classical** — no quantum PE proposed

## Experimental Results

| Model | MNIST Acc | CIFAR-10 Acc | Params |
|-------|-----------|--------------|--------|
| Classical ViT (small) | 99.1% | 78.3% | 2.1M |
| QVIT | 98.9% | 76.8% | 1.9M |
| QVIT (noiseless sim.) | 99.0% | 77.1% | 1.9M |

- QVIT roughly matches classical ViT with fewer parameters
- Tested on classical simulators (not real quantum hardware)
- Noise simulations show modest degradation (~0.3-0.5% accuracy drop)

## Key Design Choices (for Task VIII write-up)

### Option A — Replace W_Q, W_K, W_V projections (paper's approach)
```python
# Classical
Q = nn.Linear(d_model, d_k)(x)

# QVIT (paper)
Q = QuantumOrthogonalLayer(d_model, d_k)(x)
# = parameterised unitary circuit measuring d_k expectation values
```
**Pro:** Clean drop-in replacement, gradient via parameter shift rule  
**Con:** Amplitude encoding is expensive (O(2^n) gates for n qubits)

### Option B — Replace attention score computation (quantum kernel)
```python
# Classical
scores[i,j] = (Q[i] @ K[j]) / sqrt(d_k)

# Quantum kernel
scores[i,j] = |<phi(Q[i]) | phi(K[j])>|^2
# phi = quantum feature map (angle encoding)
```
**Pro:** Potentially captures non-classical correlations  
**Con:** O(T^2) circuit evaluations per layer (T = sequence length)

### Option C — Hybrid: classical QKV, quantum FFN
```python
# Keep Q, K, V classical
# Replace feedforward sublayer with VQC
x = x + MultiHeadAttention(x, x, x)   # classical
x = x + QuantumFFN(x)                 # quantum
```
**Pro:** Fewest circuit evaluations, most practical on NISQ  
**Con:** Less quantum advantage in the core attention mechanism

## Gradient Computation
All quantum layers differentiated via **parameter shift rule**:
```
d/dθ ⟨U(θ)†O U(θ)⟩ = [⟨U(θ+π/2)†O U(θ+π/2)⟩ - ⟨U(θ-π/2)†O U(θ-π/2)⟩] / 2
```
Implemented via PennyLane `diff_method='parameter-shift'`.

## Limitations Acknowledged by Authors
1. Amplitude encoding requires exponential circuit depth for arbitrary inputs
2. Results on simulators — real hardware has noise and limited qubits
3. Quantum advantage not proven — empirical results only
4. NISQ devices currently too small for practical ViT-scale models
